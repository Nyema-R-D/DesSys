# Sécurité · _Lakana_

Ne signalez pas une vulnérabilité dans une issue publique. Utilisez l'onglet **Security → Report a vulnerability** du dépôt (signalement privé).

_Ni i ye lakanali fili dɔ ye, a kana sɛbɛn issue kɔnɔ. **Security → Report a vulnerability** labaara._

Versions maintenues : la dernière version publiée.
