| ------------- | --------------------------------------------------- |
| `ci.yml`      | PR bɛɛ sɛgɛsɛgɛ : format, lint, types, tests, build |

| `release.yml` | Version kura bɔli                                   |
| `wiki.yml`    | Wiki, baara tɔw, sira jiraminɛn                     |
| `stale.yml`   | Baara minnu ma lamaga, olu datugu                   |
