# Tokens

> ⚠️ Bamanankan sɛbɛn — ka sɛgɛsɛgɛ. · [🇫🇷 Version française](Tokens)

Tokens bɛɛ sɛbɛnnen bɛ `packages/tokens/src/tokens.json` kɔnɔ. Build bɛ `tokens.css`, `index.js` ani `tokens.json` dilan. `dist/` kana yɛlɛma.

## Kulɛrw

| Token               | Kulɛr                                   | A baara         |
| ------------------- | --------------------------------------- | --------------- |
| `--ny-ink-950`      | `#0E0F0E`                               | Site ka kɔfɛ    |
| `--ny-paper-100`    | `#F2F0EA`                               | Sɛbɛnw ka kɔfɛ  |
| `--ny-laterite-500` | `#E2602E`                               | **Ɲɛgɛn kelen** |
| `--ny-status-*`     | `#7FA6E0` `#D9B04E` `#E2602E` `#5FC08A` | **Badge dɔrɔn** |

Komponanw bɛ token sémantiques labaara (`--accent`, `--text-primary`, `--surface-page`…) : u bɛ yɛlɛma ni `data-ny-theme` yɛlɛmana.

## Yɔrɔ (espacement)

`--space-1` … `--space-10` : 4, 8, 12, 16, 24, 32, 48, 64, 96, 144 px.
