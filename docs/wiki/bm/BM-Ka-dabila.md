# Fɛn minnu bɛna dabila (dépréciation)

> ⚠️ Bamanankan sɛbɛn — ka sɛgɛsɛgɛ. · [🇫🇷 Version française](Politique-de-depreciation)

1. Fɛn dɔ bɛ fɔ ko a bɛna dabila version fitinin (mineure) dɔ kɔnɔ.
2. Lasɔmini bɛ jira developpeur ma (`warnDeprecated`), production tɛ.
3. Fɛn kura bɛ di o version kelen kɔnɔ.
4. A bɛ to yen version fitinin kelen ni kalo 3 ye, ka sɔrɔ ka bɔ version belebele (majeure) nata la dɔrɔn.
5. Commit bɛ sɛbɛn ni `deprecate:` ye.
