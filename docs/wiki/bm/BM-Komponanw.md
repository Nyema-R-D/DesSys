# Komponanw

> ⚠️ Bamanankan sɛbɛn — ka sɛgɛsɛgɛ. · [🇫🇷 Version française](Composants)

Package `@nyema-r-d/react`.

| Komponan                                        | A baara                                                    |
| ----------------------------------------------- | ---------------------------------------------------------- |
| `Theme`                                         | Thème sugandi (anthracite walima paper)                    |
| `Mark`, `Logo`                                  | NYEMA taamasiyɛn                                           |
| `Button`                                        | Butɔn                                                      |
| `StatusBadge`                                   | Porogaramu cogoya (`locale="bm"` bɛ bamanankan tɔgɔw jira) |
| `TextField`                                     | Sɛbɛnni yɔrɔ                                               |
| `Select`, `Combobox`, `RadioGroup`, `Checkbox`  | Sugandili (formulaire)                                     |
| `Switch`                                        | A da wuli / a datugu                                       |
| `FileUpload`, `DateField`                       | Dosiye bila, don (date)                                    |
| `Fieldset`, `FormRow`, `FormActions`, `Stepper` | Formulaire labɛncogo                                       |
| `Chip`, `ChipGroup`                             | Sugandili                                                  |
| `SectionLabel`                                  | Label                                                      |
| `LabRow`                                        | Laboratoire ka sira                                        |
| `PillarCard`                                    | Kartu                                                      |
| `ServiceCard`, `Tag`                            | Baara kartu, taamasiyɛn                                    |
| `SignalGrid`                                    | Taamasiyɛn kare                                            |
| `Icon`, `PolygonEditor`                         | Ja fitinin (Lucide)                                        |
| `ConnectionStatus`, `OfflineBanner`             | Ɛntɛrinɛti cogoya, ɲɔgɔn sɔrɔli                            |
| `Tabs`, `Dialog`, `Drawer`, `Toast`, `Alert`    | Onglets, modale, kunnafoni fitinin                         |
| `DataTable`, `Pagination`                       | Kunnafoniw tabulo, ɲɛw                                     |
| `Breadcrumb`, `Menu`, `LinkProvider`            | Sira jira, baara sugandi                                   |
| `Accordion`, `Tooltip`                          | Yɔrɔ dayɛlɛli, ɲɛfɔli fitinin                              |
| `Skeleton`, `Progress`, `Spinner`               | A bɛ ka don (chargement)                                   |
| `Container`, `Section`                          | Ɲɛ labɛncogo                                               |
| `SiteHeader`, `Hero`, `SiteFooter`              | Site ka kɔrɔ, a daminɛ, a laban                            |
| `LanguageSwitch`                                | Kan sugandi (FR / BM)                                      |

```tsx
<StatusBadge status="research" locale="bm" />
```
